# Consumer Complaint Topic Modeling

##  Project Overview
This project performs topic modeling on consumer complaint narratives to identify common themes and issues.

## 🔧 Techniques Used
- **LDA (Latent Dirichlet Allocation)** with Bag-of-Words
- **NMF (Non-negative Matrix Factorization)** with TF-IDF

## Results
The models identify 5 key topics:
- Credit reporting issues
- Debt collection
- Loan payment problems
- Account management
- Identity theft

## Files
- `complaint_topic_modeling.ipynb` - Main analysis notebook
